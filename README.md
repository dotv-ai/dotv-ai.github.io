<h1 align="center">DOTV AI <sub>作视</sub></h1>
<p align="center"><b>AI do TV? Just DOTV it.</b></p>
<p align="center">AI-native canvas for video creation.</p>

DOTV AI ([dotv.ai](https://dotv.ai)) is an AI video creation platform: **scripts, storyboards, characters, shots, voiceover, compositing and Agent workflows on one infinite canvas.** One canvas takes an idea from script to finished film — with multi-angle shots, lighting, frame-by-frame film study (逐帧拉片), compositing and Agent automation in the same workspace.

## What's inside

- **One canvas, the whole pipeline** — script → storyboard → characters → shots → voiceover → compositing
- **Agent workflows** — hand the repetitive parts of the pipeline to an Agent and keep the creative control
- **Film study** — break any reference footage down frame by frame (逐帧拉片) and lift its language into your own shots
- **Multi-angle & lighting** — rework a shot from every angle, relight it, then regenerate only what changed
- **Team collaboration** — assets, versions and review live in the same project
